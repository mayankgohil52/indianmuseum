# 🏛️ National Museum, New Delhi — Cultural Showcase Website

A responsive, multi-page web application developed as a practical project assignment for **Web Technologies**. This project showcases the rich 5,000-year heritage of the **National Museum, New Delhi (Janpath)**, featuring architectural styling, interactive artifact galleries, official floor directories, tariff tables, and an online ticket booking system.

---

## 🛠️ Tech Stack Used
* **HTML5:** Semantic layout tags (`<header>`, `<nav>`, `<section>`, `<table>`, `<form>`, `<footer>`)
* **CSS3:** Custom heritage color palette (Delhi Red Sandstone, Ashoka Navy Blue, Antique Bronze Gold), Flexbox, CSS Grid, and hover transitions.
* **JavaScript (Vanilla):** Dynamic ticket fare calculator and client-side form validation (including mobile number checks and museum Monday-closure validation).
* **jQuery:** Interactive category filtering for museum artifacts, FAQ slide toggles, and slide-down booking confirmation alerts.

---

## 📄 Pages Included
1. **`index.html` (Home Page):** 
   * Hero banner featuring the National Museum architecture.
   * Overview of the institution and its 3 main floors/wings.
   * Highlighted masterpiece artifacts (Harappan Dancing Girl, Chola Bronze Nataraja, Mughal Miniatures).
   * Interactive FAQ section powered by jQuery (`slideToggle`).
2. **`exhibitions.html` (Galleries & Schedule):** 
   * Interactive artifact collection grid with a **jQuery-powered category filter** (Harappan, Miniatures, Coins & Jewelry).
   * Official **HTML Table** detailing floor-wise gallery directories, free guided tour timings, and ticket tariffs for Indian citizens, students, and foreign nationals.
3. **`visit.html` (Ticket Reservation Form):** 
   * Online E-ticket booking form with required inputs (*).
   * **Live JavaScript Fare Calculator** that instantly updates the total payable amount based on pass category and visitor count.
   * Robust validation script checking for valid 10-digit mobile numbers and alerting users if a Monday is selected (since the museum is closed on Mondays).

## 🎨 Theme & Color Palette
The website's visual design is inspired by the iconic architecture of Janpath, New Delhi:
* **Delhi Red Sandstone (`#8B261D`)** — Primary headers, buttons, and accents.
* **Ashoka Navy Blue (`#16263A`)** — Top notification bar, footers, and table headers.
* **Chola Bronze Gold (`#D4AF37`)** — Logo accents, badges, and highlights.
* **Dholpur Stone Cream (`#FAF6F0`)** — Clean, warm background tone.

---

## 🚀 How to Run the Project Locally
1. Clone this repository or download the ZIP folder.
2. Ensure all files (`index.html`, `exhibitions.html`, `visit.html`, and `style.css`) are kept together in the **same directory/folder**.
3. Double-click on **`index.html`** to open and test the website in any modern web browser (Google Chrome, Firefox, Edge).
